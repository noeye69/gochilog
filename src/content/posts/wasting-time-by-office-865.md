挑発的なタイトルになりましたが、悪意は全くありません。某書籍のタイトルのパクリです。

### **Googleすごい**

これに尽きるんですけど、ほんとGoogle社はすごい。恩恵受けまくり。

マイクロソフト社のOfficeがすごいのは十分わかってるんですけど、今回はOfficeをパクった(？)Google社がすごいというお話です。

### **どんなアプリがあるのか？**

|  |  |  |
| --- | --- | --- |
|  | Office | Google |
| グラフ | エクセル | スプレッドシート |
| 文章 | ワード | ドキュメント |
| プレゼン | パワポ | スライド |
| メール | outlook | Gmail |
| その他 | ？ | To Do、カレンダーなど |

表にしてみました。
操作感はちょっと違うけど、できることは同じです。「じゃあ使う必要ないじゃん」と思われるかもしれませんが、大きくメリットは２つです。

### **メリット**

---

大きく2つ。

#### **1. 横の移動がしやすい**

エクセルやワードなどのoffice系アプリだと、ファイルをPCのフォルダに個別に保存しているので、使いたいファイルが入っているフォルダを探して、そのファイルを開く、という行為が必要になりますよね。意識的にそんなことしてないけど。

Googleの場合は、スプレッドシート関連、ドキュメント関連、Gmail関連、というように、機能ごとにまとめて見れて、なおかつその移動がしやすいです。

[![](/images/wp/2019/03/sigotokourituka.jpg)](/images/wp/2019/03/sigotokourituka.jpg)

スマホで見るとこんな感じ(メールがクソ貯まってるのは置いといて)。

今の僕の仕事が、社内で言えば売上や仕入の管理、社外で言えば集計したものを送る系の仕事なので、この横の移動がしやすいのはすごい便利なんです。

[![](/images/wp/2019/03/20190310095612b1a.jpg)](/images/wp/2019/03/20190310095612b1a.jpg)

こんなイメージ。Googleは一本串。

まだ使い始めて１か月なので、エクセルやワードを使う場面というのはまだあります。お客さんから送られてくる資料はエクセルやパワポだったりするし。ドライブに放り込めば勝手に変換してくれますが。

#### **2. 共有機能がすごい**

これが最大にして最強のメリットなんですが、ファイルの共有機能がすごい便利です。

業務中、いつもエクセルに入力してるファイルを月末とか年度末に自分で整理して、上司に報告するタイミングってありませんか？そういう時、エクセルファイルをメールで送りませんか？

Googleのアプリを使えば、もうそんな必要がないんです。

例えばスプレッドシートのファイルを上司と共有設定にしておけば、自分がデータを入力したタイミングで、または上司が見たいタイミングで、PCからはもちろんスマホからもリアルタイムのデータが見れます。

メールを送らずして。

例えば、日付、お客さんの名前、品名、数量、単価、金額などが書いてある生データがあります。これを月初にまとめて、

[![](/images/wp/2019/03/matome.jpg)](/images/wp/2019/03/matome.jpg)

一体今月の仕入単価はいくらなんだい？というのを社長(父親)に報告していたんですが、このファイルを共有しておけば、

社長の立場だと

- メールが送られてくるのを待つ必要がない
- 僕が報告する月初だけじゃなく、気になったタイミングで見れる

僕の立場だと

- メールを送る必要がない
- 月初にまとめる必要がない(毎日ちょこちょこ入力すればいい)

と、お互いにメリットしかありません。

他にも、いろんな人が書き込む紙媒体のノートがあったんですけど、もう全部スプレッドシートでよくね？という。

### **他にもメリットありまくり**

- ファイルを消してしまっても変更履歴から復活できる

共有によっていろんな人が使うことになるので、誰かが間違って消しちゃったとかが起こりうる。あとPCの急なシャットダウンとか。

そんなことが起こっても大丈夫。変更履歴からデータを復活させることができます。常に自動保存されているので安心です。どんだけ膨大なデータを持っているんだGoogleはという感じですが。

- Officeとの互換性がすごい

上にもちらっと書きましたが、ドライブという場所に例えばエクセルを放り込めば、勝手にスプレッドシートに変換してくれます。なので、今使ってるファイルを放り込むだけで今日からデビューできます。

会社では独自ドメイン取得してるからちょろっとお金かかってますが、個人で使う分には無料でOfficeの機能が使えるってヤバい。今まで何のためにOffice入りのパソコン使ってたんだ…という気持ちになりますね。と同時に、Googleは何で儲けてるんだという疑問すら浮かぶ(広告収入だそうです)。

### **こんな人にオススメ**

- メールでエクセルやパワポを送ってる人
- 生データ的なものをまとめて報告してる人
- スケジュール管理とかしてる人

なんですが、全てのGoogleのサービスの恩恵を受けるなら、会社としてG Suiteというビジネス版を導入した方がいいので、大企業とかだと今更やりづらそう。メールのシステムとかすでにあるし。

でもスプレッドシートやスライドだけでも十分に恩恵を受けれるはずなので、使ってみて損はないかと思います。もうエクセルには戻れない…。

以上です。
